# Ping

Alertes instantanées sur les nouvelles annonces Leboncoin, Facebook Marketplace, Vinted et eBay.

- Site : https://mounirzayn.github.io/ping/
- Espace perso : https://mounirzayn.github.io/ping/app.html
- Appli Mac : onglet Releases

L'appli Mac surveille les recherches avec les sessions de l'utilisateur et publie les alertes sur un canal ntfy privé.
L'espace web lit ce canal et envoie ses commandes au Mac via `<canal>-cmd`.
